# Mejoras despues del primer modelo

Cuando el flujo principal funcione, mejora el proyecto en este orden:

1. Revisar valores nulos.
2. Revisar clases desbalanceadas.
3. Comparar Random Forest con Logistic Regression.
4. Usar `GridSearchCV` para ajustar hiperparametros.
5. Guardar metricas en un archivo.
6. Crear una interfaz Tkinter para introducir un jugador y predecir.
7. Crear graficos de distribucion con matplotlib.
8. Documentar resultados en un README.

No empieces por optimizar. Primero entiende el flujo completo.

# 01 - Introduccion a Python

Python es un lenguaje de programacion usado para automatizacion, analisis de datos, backend, inteligencia artificial, scripts, pruebas y herramientas internas.

## Que es programar

Programar es darle instrucciones precisas a la computadora. Un programa normalmente:

1. Recibe datos.
2. Procesa esos datos.
3. Produce una salida.

Ejemplo:

```python
nombre = input("Tu nombre: ")
print("Hola", nombre)
```

## Tu primer programa

Crea un archivo llamado `hola.py`:

```python
print("Hola, Python")
```

Ejecutalo:

```powershell
python hola.py
```

## Errores

Los errores son parte normal del aprendizaje. Aprende a leer:

- Tipo de error: que fallo.
- Archivo: donde fallo.
- Linea: en que linea fallo.
- Mensaje: pista concreta.

Ejemplo:

```python
print("hola"
```

Esto produce un error de sintaxis porque falta cerrar el parentesis.

## Comentarios

```python
# Esto es un comentario
print("Esto si se ejecuta")
```

Usa comentarios para explicar decisiones, no para repetir lo obvio.

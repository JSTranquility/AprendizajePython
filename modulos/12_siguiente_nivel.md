# 12 - Siguiente nivel

Cuando domines este curso, elige una ruta.

## Backend web

Aprende:

- HTTP
- Flask o FastAPI
- Bases de datos
- Autenticacion
- Despliegue

## Datos

Aprende:

- pandas
- numpy
- matplotlib
- limpieza de datos
- notebooks

## Automatizacion

Aprende:

- pathlib
- shutil
- schedule
- selenium o playwright
- procesamiento de archivos

## Buenas practicas profesionales

- Git y GitHub
- pruebas automaticas
- logging
- type hints
- documentacion
- estructura de paquetes

## Proyectos recomendados

- API de tareas con FastAPI.
- Dashboard de gastos.
- Bot que organiza archivos.
- Scraper responsable de precios.
- Sistema de inventario con SQLite.

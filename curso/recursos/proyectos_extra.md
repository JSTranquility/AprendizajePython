# Proyectos extra para practicar

## Principiante

- Conversor de temperaturas.
- Calculadora de propinas.
- Generador de contrasenas.
- Adivina el numero.
- Agenda de contactos en JSON.

## Intermedio

- Inventario con SQLite.
- Registro de ventas.
- Buscador de archivos duplicados.
- Organizador de carpetas por extension.
- CLI para tomar notas.

## Avanzado inicial

- API REST con FastAPI.
- Dashboard de gastos con pandas.
- Bot que consulta una API.
- Scraper responsable con limites de tiempo.
- Aplicacion web simple con Flask.

## Regla para aprender con proyectos

Cada proyecto debe tener:

- Entrada de datos.
- Validacion.
- Logica separada en funciones.
- Persistencia si aplica.
- Pruebas para la logica principal.
- README con instrucciones.

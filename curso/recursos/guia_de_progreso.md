# Guia de progreso

Marca cada punto cuando puedas hacerlo sin mirar ejemplos.

## Fundamentos

- [ ] Ejecutar archivos `.py` desde terminal.
- [ ] Usar `print` e `input`.
- [ ] Crear variables con nombres claros.
- [ ] Convertir entre `str`, `int`, `float` y `bool`.
- [ ] Usar `if`, `elif`, `else`.
- [ ] Usar `for` y `while`.
- [ ] Escribir funciones con parametros y `return`.

## Colecciones

- [ ] Crear y modificar listas.
- [ ] Recorrer listas con `for`.
- [ ] Usar diccionarios.
- [ ] Agrupar datos con diccionarios.
- [ ] Eliminar duplicados con `set`.
- [ ] Usar comprensiones de listas.

## Programas reales

- [ ] Manejar errores con `try` y `except`.
- [ ] Separar logica en funciones.
- [ ] Leer y escribir archivos.
- [ ] Guardar datos en JSON.
- [ ] Crear clases simples.
- [ ] Crear programas de consola con menu.

## Calidad

- [ ] Escribir pruebas con `assert`.
- [ ] Escribir pruebas con `unittest`.
- [ ] Probar casos normales y casos limite.
- [ ] Evitar duplicacion innecesaria.
- [ ] Usar nombres claros.

## Datos y herramientas

- [ ] Leer y escribir CSV.
- [ ] Crear una base SQLite.
- [ ] Insertar y consultar datos.
- [ ] Crear un entorno virtual.
- [ ] Instalar paquetes con `pip`.
- [ ] Consumir una API.

## Nivel intermedio

- [ ] Organizar un proyecto en carpetas.
- [ ] Usar `pathlib`.
- [ ] Usar type hints basicos.
- [ ] Entender errores comunes.
- [ ] Leer documentacion oficial.
- [ ] Subir un proyecto a GitHub.

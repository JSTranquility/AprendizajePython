# Glosario

- Algoritmo: pasos para resolver un problema.
- Argumento: valor que se pasa a una funcion.
- Booleano: valor `True` o `False`.
- Bug: error en el programa.
- Clase: plantilla para crear objetos.
- Diccionario: estructura clave-valor.
- Excepcion: error que ocurre al ejecutar.
- Funcion: bloque reutilizable de codigo.
- Iteracion: una vuelta de un bucle.
- Lista: coleccion ordenada y modificable.
- Metodo: funcion dentro de una clase.
- Modulo: archivo Python importable.
- Objeto: instancia de una clase.
- Parametro: nombre que recibe un valor dentro de una funcion.
- Scope: zona donde una variable existe.
- String: texto.
- Tupla: coleccion ordenada no modificable.

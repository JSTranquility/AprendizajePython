# 🌶️ Especialización en Flask

Flask es un "micro-framework" de Python para crear aplicaciones web. Se llama micro porque no requiere herramientas o librerías particulares, permitiéndote elegir cómo estructurar tu app.

## 🎯 Conceptos Clave
1. **Rutas (@app.route)**: Cómo mapear una URL a una función de Python.
2. **Templates (Jinja2)**: Renderizar HTML dinámico pasando variables desde Python.
3. **Métodos HTTP**: Entender la diferencia entre `GET` (pedir datos) y `POST` (enviar datos).
4. **Formularios**: Cómo recibir información del usuario y procesarla.
5. **Contexto de Aplicación**: Manejo de sesiones y cookies.

## 🚀 Tu Primer Desafío
Crea una aplicación Flask simple que:
- Tenga una página de inicio (`/`) que diga "¡Hola, aprendiz!".
- Tenga una ruta `/saludo/<nombre>` que muestre un saludo personalizado usando el nombre de la URL.
- Use una plantilla HTML (archivo `.html`) para renderizar el saludo.

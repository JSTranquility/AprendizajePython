# 🎸 Especialización en Django

Django es un framework de alto nivel que fomenta el desarrollo rápido y el diseño limpio. Es famoso por incluir "baterías incluidas" (trae casi todo lo que necesitas por defecto).

## 🎯 Conceptos Clave
1. **Patrón MTV (Model-Template-View)**: La arquitectura de Django.
2. **ORM (Object-Relational Mapper)**: Interactuar con la base de datos usando clases de Python en lugar de SQL.
3. **Admin Interface**: El panel de administración que se genera automáticamente.
4. **Migrations**: Cómo Django gestiona los cambios en el esquema de la base de datos.
5. **Middleware y Seguridad**: Protección contra ataques comunes (CSRF, XSS, etc.).

## 🚀 Tu Primer Desafío
Crea un proyecto Django llamado `mi_sitio` y una app llamada `blog`:
- Define un modelo `Post` con `titulo`, `contenido` y `fecha_publicacion`.
- Registra el modelo en el `admin.py` para verlo en el panel de control.
- Crea una vista que liste los títulos de los posts en una página HTML.

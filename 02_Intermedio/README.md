# 🟡 Fase 2: Python Intermedio y POO

En esta fase dejamos de escribir "scripts" y empezamos a construir "software". Aprenderás a organizar código complejo y a manejar errores como un profesional.

## 📖 Temario
1.  **Manejo de Errores y Excepciones**: Hacer tu código robusto.
2.  **Programación Orientada a Objetos (POO)**: Clases, objetos y herencia.
3.  **Pruebas (Testing)**: Asegurar que tu código funciona.
4.  **APIs y Entornos**: Cómo consumir datos externos y gestionar librerías.
5.  **Conceptos Avanzados**: Decoradores, generadores y más.

## 🛠️ Práctica
Consulta la carpeta `roadmaps/` para profundizar en temas específicos de lógica avanzada.

# 🟠 Fase 3: Dominio de Datos (SQL)

La mayoría de las aplicaciones necesitan guardar datos de forma permanente. En esta fase aprenderás a conectar Python con bases de datos SQL.

## 📖 Temario
1.  **Fundamentos de SQL**: Tablas, tipos, CRUD.
2.  **SQLite**: Base de datos ligera incluida en Python.
3.  **MySQL**: Conexión con servidores de bases de datos profesionales.
4.  **Integración con Python**: Uso de `sqlite3` y drivers de MySQL.

# Soluciones

Los archivos de `ejercicios/` ya incluyen implementaciones funcionales y pruebas con `assert`.

Para practicar de verdad:

1. Copia mentalmente el enunciado de cada funcion.
2. Borra la implementacion.
3. Intenta resolverla sin mirar.
4. Ejecuta el archivo.
5. Si falla, lee el error y corrige.

# 🏛️ Especialización en PyQt (PySide)

PyQt es un conjunto de bindings de Python para el framework Qt, uno de los más potentes para crear aplicaciones profesionales de escritorio.

## 🎯 Conceptos Clave
1. **Signals and Slots**: El sistema de comunicación entre objetos en Qt (muy potente).
2. **Qt Designer**: Una herramienta visual para arrastrar y soltar componentes.
3. **QObjects y Herencia**: Estructura de clases de Qt.
4. **Layouts Complejos**: `QVBoxLayout`, `QHBoxLayout`, `QGridLayout`.
5. **Estilos (QSS)**: Personalizar la apariencia usando algo muy similar a CSS.

## 🚀 Tu Primer Desafío
Crea una ventana con PyQt que:
- Tenga un menú superior con una opción "Archivo" -> "Salir".
- Tenga un botón central que, al presionarlo, cambie el texto de un `QLabel`.
- Usa un archivo `.ui` generado con Qt Designer y cárgalo desde Python.

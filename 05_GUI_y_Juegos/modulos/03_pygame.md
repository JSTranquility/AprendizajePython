# 🎮 Especialización en Pygame

Pygame es un conjunto de módulos de Python diseñados para escribir videojuegos. Incluye librerías de gráficos y sonido que funcionan de forma multiplataforma.

## 🎯 Conceptos Clave
1. **El Bucle Principal (Game Loop)**: Procesar eventos -> Actualizar lógica -> Dibujar en pantalla.
2. **Superficies (Surfaces) y Rectángulos (Rects)**: Cómo se representan los objetos y se detectan colisiones.
3. **Manejo de Eventos**: Detectar teclas presionadas, movimientos del mouse o cierre de ventana.
4. **FPS (Frames Per Second)**: Controlar la velocidad del juego.
5. **Sprites**: Organización de objetos complejos en el juego.

## 🚀 Tu Primer Desafío
Crea una ventana de Pygame que:
- Tenga un fondo de color sólido.
- Muestre un cuadrado (o un círculo) que el usuario pueda mover usando las flechas del teclado.
- Asegúrate de que el cuadrado no se salga de los límites de la ventana.

# 🖼️ Especialización en Tkinter

Tkinter es la librería estándar de Python para crear Interfaces Gráficas de Usuario (GUI). Viene instalada por defecto y es la más sencilla para empezar.

## 🎯 Conceptos Clave
1. **Widgets**: Botones (`Button`), etiquetas (`Label`), entradas de texto (`Entry`).
2. **Layout Managers**: Cómo organizar elementos usando `pack()`, `grid()` o `place()`.
3. **Variables de Tkinter**: `StringVar`, `IntVar` para vincular datos a la interfaz.
4. **Event Binding**: Ejecutar funciones cuando el usuario hace clic o presiona una tecla.
5. **Mainloop**: El ciclo que mantiene la ventana abierta y respondiendo.

## 🚀 Tu Primer Desafío
Crea una "Calculadora de Edad":
- Un campo donde el usuario ingrese su año de nacimiento.
- Un botón que diga "Calcular".
- Una etiqueta que muestre el resultado (la edad aproximada).

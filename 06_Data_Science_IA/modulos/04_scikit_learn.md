# 🤖 Especialización en Scikit-Learn

Scikit-learn es la librería estándar para Machine Learning "clásico" en Python. Cubre clasificación, regresión, clustering y reducción de dimensionalidad.

## 🎯 Conceptos Clave
1. **Modelos Supervisados**: Regresión Lineal, Árboles de Decisión, KNN.
2. **Modelos No Supervisados**: K-Means, PCA.
3. **Preprocesamiento**: Escalar datos, codificar variables categóricas.
4. **Validación**: División entre entrenamiento y prueba (`train_test_split`), validación cruzada.
5. **Métricas**: Precisión (Accuracy), R², Matriz de Confusión.

## 🚀 Tu Primer Desafío
Crea un modelo que prediga si una flor pertenece a una especie u otra usando el famoso dataset `iris`:
- Carga el dataset desde `sklearn.datasets`.
- Divide los datos en entrenamiento y prueba.
- Entrena un modelo de `KNeighborsClassifier`.
- Muestra la precisión (accuracy) del modelo.

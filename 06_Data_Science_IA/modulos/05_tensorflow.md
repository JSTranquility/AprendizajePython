# 🧠 Especialización en TensorFlow / Keras

TensorFlow es una plataforma de código abierto para aprendizaje automático. Keras es la API de alto nivel que corre encima de TensorFlow para facilitar la creación de Redes Neuronales.

## 🎯 Conceptos Clave
1. **Tensores**: La unidad básica de datos (similar a los arrays de NumPy pero procesables en GPU).
2. **Capas (Layers)**: `Dense`, `Conv2D`, `Dropout`, `LSTM`.
3. **Modelos**: Secuenciales vs API Funcional.
4. **Compilación**: Optimizadores (`Adam`), Funciones de Pérdida (`Loss`) y Métricas.
5. **Entrenamiento**: Épocas (`epochs`), tamaño de lote (`batch_size`).

## 🚀 Tu Primer Desafío
Crea una red neuronal simple que aprenda la relación $y = 2x - 1$:
- Define un modelo con una sola capa densa.
- Entrénalo con unos pocos datos de ejemplo.
- Pídele que prediga el valor de $y$ para un $x$ que no haya visto.

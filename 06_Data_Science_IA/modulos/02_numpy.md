# 🔢 Especialización en NumPy

NumPy es la base de casi todo el ecosistema científico de Python. Proporciona arrays multidimensionales y funciones matemáticas de alto rendimiento.

## 🎯 Conceptos Clave
1. **Arrays (ndarrays)**: Diferencia entre una lista de Python y un array de NumPy.
2. **Broadcasting**: Cómo NumPy opera con arrays de diferentes tamaños.
3. **Indexación y Slicing**: Selección avanzada de datos en matrices.
4. **Funciones Matemáticas**: Álgebra lineal, estadísticas, transformadas.
5. **Vectores y Matrices**: Operaciones fundamentales para Machine Learning.

## 🚀 Tu Primer Desafío
Crea un script que:
- Genere un array de 10x10 con números aleatorios.
- Calcule la suma de cada fila.
- Encuentre el valor máximo y mínimo de toda la matriz.
- Invierta el orden de las filas.

# 🐼 Especialización en Pandas

Pandas es la herramienta principal para manipulación y análisis de datos en Python. Es como tener un Excel superpotente dentro de tu código.

## 🎯 Conceptos Clave
1. **Series y DataFrames**: Las estructuras de datos fundamentales.
2. **Lectura de Datos**: Cargar archivos CSV, Excel, SQL o JSON.
3. **Limpieza de Datos**: Manejo de valores nulos (`NaN`), duplicados y tipos de datos.
4. **Filtrado y Agregación**: `groupby`, `sum`, `mean`, y filtros condicionales.
5. **Merge y Join**: Combinar diferentes fuentes de datos.

## 🚀 Tu Primer Desafío
Descarga un dataset simple (como el de pasajeros del Titanic o uno de ventas):
- Cárgalo en un DataFrame.
- Muestra las primeras 5 filas.
- Calcula el promedio de una columna numérica.
- Filtra las filas que cumplan una condición específica.
